# Regex Word Generator

A C program that generates words from a **regular expression** based on a given **alphabet**.  
It simulates a simple formal language generator and checks whether a given word belongs to the generated language.

---

## 🚀 Features

- Accepts a user-defined alphabet (e.g. `a,b`)
- Validates if the regular expression can be built from the alphabet
- Supports `*`, `+`, and `()` operators
- Generates a user-specified number of words from the language
- Checks if a given word belongs to the generated language
